## Kalibrační anchory
- 80–100: velmi silná opportunity (Reality PASS + více nezávislých signálů + jasný demand)
- 60–79: solidní (dobré signály, ale něco není ideální)
- 40–59: slabé/nejisté (omezená evidence, vyšší saturace)
- 0–39: nedostatečné → MONITOR/DROP

## Discover vs. Search rozlišení (KRITICKÉ)
LSA: 66 % CZ traffiku je Discover → prioritizovat Discover briefs

**SEARCH brief:** keyword-first titulek, long-tail, FAQ, schema markup
**DISCOVER brief:** emoční hook, silný thumbnail (podmínka!), engagement-first, max 24–48h čerstvost

Každé doporučení označit: `[SEARCH]` `[DISCOVER]` nebo `[OBOJÍ]`

## PAGE FRESHNESS ≠ INFORMATION FRESHNESS (V6.5 sekce 6)
Stránka aktualizovaná dnes může popisovat informaci oznámenou před měsíci.
Vždy zjistit ORIGINAL INFORMATION FIRST-PUBLIC TIME.
Pokud je informace stará pro svůj typ → REQUIRES REFRESH + snížit confidence.

## Kanibalizace — UPDATE před CREATE (povinné)
Ze SEO auditu: 180 URL na dotaz "iphone 18" na LSA. Systémový problém.

Před každým CREATE:
1. WP search na téma (krátký + dlouhý tvar + bez brandu + slug)
2. Existuje? → UPDATE nebo REWRITE, ne nový článek
3. Výstup: `CREATE` / `UPDATE [URL]` / `REWRITE [URL]` / `MERGE` / `MONITOR` / `DROP`
