## V6.5 WP Draft formát (editor-first, V6.5 sekce 21)
Pořadí v briefu:
1. EDITORIAL PRIORITY (0–100) + MUST WRITE / SHOULD WRITE / OPTIONAL / MONITOR / DROP
2. ACTION: CREATE / UPDATE / REWRITE / MERGE / FOLLOW-UP / MONITOR / DROP
3. Autor + Timing
4. Reality + Confidence (PASS/UNCERTAIN/FAIL | HIGH/MEDIUM/LOW)
5. Doporučený titulek (+ volitelně DISCOVER ALT a SEARCH ALT)
6. Úhel článku
7. Co musí článek zodpovědět
8. Unique Value (KONKRÉTNÍ — ne "vysvětlit lépe")
9. Povinné podklady / screenshoty / přesné ověření
10. Teprve pak: LISA ANALYSIS (scoring, GSC, Trends, evidence)

## Titulky per web + typ
- Search: keyword-first ("Samsung Galaxy S25 Ultra vs. iPhone 16 Pro: který fotí lépe?")

- LSA: Apple-first framing
- Android Magazine: Android/Google/Pixel zaměření
- Samsung Magazine: Samsung/One UI zaměření
