SEO Technical — Strengths

✓ robots.txt: Excellent — blokuje plugin dirs, search pages, tag archives, UTM params. Normalizuje strukturu.
✓ XML Sitemaps: 120+ měsíčních + index. Plugin: XML Sitemap & Google News v5.5.8. S image sitemap references.
✓ hreflang: 40+ jazyků, xhtml:link implementace. x-default pointing to EN/. Professional setup.
✓ URL Structure: /[keyword-slug]/ — SEO friendly, bez UTM pollutions.
✓ HTTPS + Security: HSTS enabled, security headers present. Mixed content ✓ clean.

SEO Technical — Weaknesses

✗ Missing Article Schema: Chybí NewsArticle + Article JSON-LD schema na postech. To je low-hanging fruit pro SEO improvement.
✗ Missing FAQ Schema: Žádný FAQ schema na review/guide článcích. Featured snippet opportunity lost.
✓ E-E-A-T Author Bios: Výborné — každý autor má detailní bio s historií a specialitami. Amaya: "Nadšení pro Apple od iPhone 4...", speciality: chytrá domácnost, IoT, hudba + tech.
✗ Promo/Editorial Mix: Komerční obsah (Alza deals, QNAP PR) smíchán s editoriálem bez jasného oddělení. Google algoritmus to vidí negativně.
✗ No Breadcrumb Schema: Chybí BreadcrumbList schema pro navigační cestu. Navigation SERPs loss.
